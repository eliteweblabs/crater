# Default New Client Invoice Items

Here are the core services that should be included in the initial invoice for any new client website project:

## Website Setup
- Domain name registration (1 year)
- Website hosting on Railway (1 year)
- SSL certificate installation
- Domain transfer to name.com

## Hosting & Infrastructure
- Google Workspace setup and configuration
- Google Webmaster Tools account connection
- Google API authentication setup
- Supabase database hosting (1 year)
- Supabase database setup and configuration

## Design & Branding
- Logo design
- Brand identity guidelines
- Custom homepage design
- Mobile-responsive layout

## Development
- WordPress/CMS installation and configuration
- Custom theme development
- Plugin installation and setup
- E-commerce integration (if required)

## Project Management
- Initial client kickoff meeting
- Weekly status updates
- Launch planning and deployment

## Training & Documentation
- Content management system training
- Website administration guide
- Launch checklist and support resources

## VAPI Phone Agent
- VAPI agent configuration
- Generate agent script
- Configure and connect phone number

This baseline set of services ensures a new client website is properly set up, branded, developed, and supported from the start. Additional features, integrations, or ongoing maintenance can be added as needed for each unique client project.
